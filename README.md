# Многоборье ГТО России — мобильное приложение

Мобильное веб-приложение (PWA) Федерации многоборья ГТО России: официальный календарь соревнований, новости, реестр рекордов, медиацентр, региональные отделения и справочные инструменты. Все данные берутся из первоисточника **[gto.com.ru](https://gto.com.ru/)** — без выдуманных функций, live-заглушек и имитации авторизации.

- **Прод:** http://201.51.30.44:8080/
- **Первоисточник данных:** https://gto.com.ru/
- **Версия офлайн-кэша:** `v28`

## Что внутри

Одностраничное приложение (SPA) с нижней навигацией из 5 разделов (Главная, Старты, Новости, Медиа, Рекорды) и дополнительными автономными экранами, доступными из раздела «Ещё» и с главной. Всего **20 экранов**.

## Экраны и функции

### Основные разделы (нижняя навигация)
- **Главная** — живое видео на фоне hero, лента последних новостей, быстрый доступ (Календарь, Рекорды, Документы, Связаться) с векторными иконками.
- **Старты (Календарь)** — 113 соревнований; фильтры по статусу (Все / Идёт регистрация / Предстоящие / Прошедшие) и по годам; статус-пилюля на каждой карточке. Регистрация показывается только для непрошедших событий.
- **Новости** — 77 публикаций с поиском; полный текст открывается внутри приложения, ссылка на оригинал сохраняется.
- **Медиа** — видео (фильтр Все / Rutube / VK, адаптивный плеер 16:9) и фотоальбомы VK (галерея с пагинацией).
- **Рекорды** — 321 запись; фильтры по полу, возрасту, дисциплине; группировка; иконки дисциплин.

### Деталь соревнования
Обложка, описание, вкладки **О событии / Результаты / Документы / Фото**. Результаты личных зачётов показываются карточками (место, имя, регион, медаль с цветом), сложные командные таблицы — прокручиваемыми таблицами. Кнопка «Добавить в календарь (.ics)» и сверка с первоисточником.

### Автономные разделы Федерации
- **О Федерации** — определение вида спорта, статистика, история, дисциплины (данные с gto.com.ru).
- **Руководство** — состав руководящих органов.
- **Региональные федерации** — интерактивная карта России с точками отделений (клик открывает регион), поиск, фильтр по федеральным округам, поиск ближайшего отделения по геолокации, **гербы всех регионов**, контакты и маршрут в Яндекс.Картах.
- **Документы** — учредительные и уставные документы (PDF с официального сайта).
- **Антидопинг** — материалы и контакты РУСАДА.

### Справочные инструменты
- **Калькулятор ступеней** — нормативы I–XVIII ступеней (Приказ Минспорта России № 114); реактивный расчёт на Золотой/Серебряный/Бронзовый знак, сравнение с рекордами РФ, справка о государственных льготах (налоговый вычет по ст. 218 НК РФ, баллы к ЕГЭ, стипендия). Плавный слайдер возраста.
- **Тренировочный таймер** — интервальные режимы (Табата, EMOM, AMRAP, Секундомер) со звуком через Web Audio API.
- **Судейские стандарты** — критерии зачёта и незачёта (No-Rep) повторений по упражнениям.
- **Поиск атлета** — сквозной поиск по **3 442 профилям** с раскрываемой историей выступлений и рекордов; полный каталог загружается только при первом поиске и сохраняется для офлайн-работы.

## Данные

Все данные импортированы из **gto.com.ru** скриптами в каталоге `scripts/` и хранятся статически:

- `web/js/gto_data.js` — новости, календарь, рекорды, региональные федерации, видео, нормативы калькулятора.
- `web/js/vk_albums_data.js` — фотоальбомы VK.
- `web/js/standards_data.js` — судейские критерии (зачёт / No-Rep).
- `web/data/events/*.json` — детальные карточки соревнований (описание, результаты, документы) для событий, у которых есть страница на gto.com.ru.
- `web/data/master/athletes.json` — оптимизированный публичный каталог из 3 442 атлетов для автономного поиска.
- `web/assets/coats/*.png` — гербы регионов (источник — Wikidata / Wikimedia Commons).

Полные исходные выгрузки находятся в `database_dumps/`: SQLite-база, мастер-JSON, 123 страницы турниров, 4 869 строк протоколов, 321 рекорд и каталог атлетов. Метаданные нового турнирного парсера пока не заменяют основной календарь: его поля дат требуют дополнительной очистки. Приложение использует проверенный календарь из `gto_data.js`, а из нового дампа — валидированный каталог атлетов.

События без отдельной страницы на первоисточнике показывают карточку с базовыми сведениями из календаря и ссылкой на официальный сайт — без придуманных результатов.

## Технологии

- **Ядро:** Vanilla ES6-модули, без фреймворков.
- **Стили:** CSS с переменными (`css/mobile.css`, `css/detail.css`, `css/autonomy.css`); тёмная тема, иконки — только инлайн-SVG (Zero-Emoji).
- **Шрифты:** Google Fonts `Unbounded` (заголовки) + `Inter` (текст), загрузка без блокировки рендера.
- **PWA:** `manifest.webmanifest` + service worker (`sw.js`) с офлайн-кэшем и версионированием.
- **Сервер:** Nginx (статика), gzip включён.
- **Производительность:** Lighthouse (mobile) — Performance ~86, Accessibility 100; LCP ~1.9s (отложенная загрузка hero-видео, webp-постер).

## Локальный запуск

Сборка не требуется — это статическое приложение.

```bash
cd web
python3 -m http.server 4173
```

Открыть: `http://localhost:4173/`

## Деплой

Прод — Nginx на `root@201.51.30.44`, каталог `/var/www/gto2026/`, порт `8080`.

```bash
rsync -az -e "ssh -i ~/.ssh/crossfit_prod_ed25519 -o StrictHostKeyChecking=no" \
  web/ root@201.51.30.44:/var/www/gto2026/ \
  && ssh -i ~/.ssh/crossfit_prod_ed25519 -o StrictHostKeyChecking=no root@201.51.30.44 "nginx -s reload"
```

> При каждом деплое поднимайте версию ассетов (`?v=N` в `index.html` и `VERSION` в `sw.js`) для сброса кэша.

## Обновление данных

Данные обновляются скриптами импорта в `scripts/` (обход gto.com.ru, парсинг новостей, результатов и федераций). После импорта пересобираются `gto_data.js` и `web/data/events/*.json`, затем выполняется деплой.

## Принципы проекта

- **Только реальные данные первоисточника.** Никаких выдуманных турниров, результатов, судейств или live-заглушек.
- **Автономность.** Основной контент (новости, результаты, разделы Федерации) открывается внутри приложения; внешняя ссылка — для проверки, а не как единственный способ навигации.
- **Честность интерфейса.** Приложение не выдаёт себя за систему судейства, ЕСИА или сервис регистрации; регистрация показывается только там, где она реально открыта.
