## 📖 О проекте

Цифровая платформа **Общероссийской общественной организации «Федерация многоборья ГТО России»** — это автономное спортивное мобильное приложение (PWA) и нативная Android-оболочка (Jetpack Compose), синхронизированные с официальным первоисточником [gto.com.ru](https://gto.com.ru/).

* **Вид спорта**: «Многоборье ГТО» (официально признан Минспортом России 28 марта 2023 года)
* **Номер-код ВРВС**: `1810001411Я`
* **Единый календарный план Минспорта РФ**: № 216
* **Президент Федерации**: **Кемал Шаманов**

Все данные приложения строго верифицированы: полностью исключены вымышленные судейские VAR-статусы, демонстрационные профили Госуслуг и нерелевантные кроссфит-комплексы. Используются исключительно официальные протоколы, нормативные приказы Минспорта РФ и открытые материалы пресс-службы.

* **Боевой сервер**: [http://201.51.30.44:8080/](http://201.51.30.44:8080/)
* **Официальный портал**: [https://gto.com.ru/](https://gto.com.ru/)

## ⚡ Ключевые возможности экосистемы

* 🏆 **Календарь ЕКП (113 стартов)**: полная база официальных соревнований 2021–2026 гг. с фильтрами по городам/регионам, форматам соревнований и статусам регистрации. Детальные экраны включают положения, расписания, протоколы и ссылки на прямую регистрацию.
* 🥇 **Официальный Реестр рекордов России**: 321 высшее спортивное достижение с классификацией по полу, возрасту и дисциплинам, сегментированным управлением и генерацией карточек шеринга для соцсетей.
* 🎯 **Калькулятор 18 ступеней комплекса ГТО**: расчет нормативов Минспорта России (Приказ № 114) с моментальной реактивной оценкой результатов на Золотой, Серебряный и Бронзовый знак отличия, сравнением с рекордами РФ и справкой о государственных льготах (налоговый вычет по НДФЛ 18 000 руб., баллы к ЕГЭ, повышенная стипендия).
* ⏱️ **Тренировочный таймер WOD**: профессиональный интервальный таймер для многоборья ГТО со звуковым сопровождением (Web Audio API, частотный синтез без внешних аудиофайлов) и виброоткликом: режимы **Табата**, **EMOM**, **AMRAP**, **For Time**.
* 🔍 **Сквозной поиск атлета по протоколам**: мгновенный поиск любого спортсмена по всем загруженным итоговым протоколам соревнований с отображением занятого места, очков и возраста.
* 🎥 **Медиацентр Rutube и VK**: официальный видеоархив с адаптивным плеером 16:9 и галерея из 19 турнирных фотоальбомов ВКонтакте, сконвертированных в легковесный локальный формат WebP с поддержкой полноэкранного свайп-лайтбокса.
* 📐 **Судейские стандарты и No-Rep**: официальные критерии зачета повторений и типичные ошибки судейства для всех основных упражнений (отжимания, подтягивания, рывок гири, прыжок в длину, наклон на скамье).
* 🗺️ **Интерактивная карта 49 отделений**: адреса и контакты региональных отделений с автоопределением ближайшего отделения по GPS-координатам атлета.
* 📲 **Генератор карточек достижений**: создание персонализированных брендовых карточек (рекорды, знаки отличия, результаты) на HTML5 Canvas с возможностью отправки через системный диалог Web Share API или сохранения фото в память устройства.
* ⚡ **100% автономность и офлайн (PWA v21)**: Service Worker кэширует все ключевые экраны, данные и медиафайлы — приложение полноценно открывается и работает даже в авиарежиме или при отсутствии мобильного интернета.

## 🎨 Интерфейс и пользовательский опыт (Mobile-Native)

Интерфейс приложения спроектирован по гайдлайнам Apple Human Interface Guidelines и Google Material 3 Design:

1. **Segmented Controls**: слитные переключатели в углубленной подложке (`[ Все | Мужчины | Женщины ]`, `[ Видео | Фото VK ]`, переключатель режимов таймера) вместо разрозненных кнопок.
2. **Капсульные фильтры (Filter Pills)**: горизонтальные прокручиваемые пилюли для выбора городов, дисциплин, возраста и группировки с кастомными стрелочками и компактными метками.
3. **Группированные списки (iOS Grouped Table View)**: экран «Федерация / Ещё» организован в виде единого стеклянного контейнера со скругленными углами и деликатными линиями-разделителями.
4. **Устранение визуального шума**: карточки рекордов превращены в аккуратные кликабельные строки с компактной микрокнопкой шеринга 34×34px вместо 100+ громоздких текстовых кнопок.
5. **Безупречная работа с полями ввода**: точечное реактивное обновление значений в калькуляторе предотвращает перерендер DOM и гарантирует стабильность мобильной клавиатуры и позиции каретки при наборе данных.

## 🖥️ Функциональные модули приложения

### 1. Главная страница (`home`)
* **Hero-секция**: динамический видеофон с адаптивным постером, официальным слоганом и кнопкой быстрого перехода к стартам.
* **Лента новостей**: горизонтальный слайдер последних официальных публикаций.
* **Быстрый доступ (Action Grid)**: карточки прямого перехода: «Календарь», «Калькулятор 18 ступеней», «Таймер WOD», «Судейские стандарты», «Поиск атлета», «Рекорды России», «Документы», «Связаться».

### 2. Календарь соревнований (`events` / `event`)
* **113 стартов ЕКП**: хронологический список соревнований Минспорта РФ с 2021 по 2026 год.
* **Фильтры**: удобные капсулы выбора региона/города и формата старта (Кубки и Первенства, Чемпионаты России, Игры ГТО, Дальний Восток).
* **Статусы**: «Все», «Идёт регистрация», «Предстоящие», «Прошедшие».
* **Карточка турнира (`event`)**:
  * Вкладка **«О событии»**: даты, место проведения, описание дисциплины, кнопка регистрации.
  * Вкладка **«Результаты»**: таблицы итоговых протоколов с очками, местами и личными карточками медалистов.
  * Вкладка **«Документы»**: официальные регламенты и положения в PDF.
  * Вкладка **«Фото»**: привязанная галерея снимков с данного старта.

### 3. Пресс-служба (`news` / `article`)
* Официальные новости Федерации без стороннего контента.
* Мгновенный полнотекстовый поиск.
* Чтение полных статей прямо в приложении с форматированным текстом и иллюстрациями.

### 4. Медиацентр (`media`)
* **Сегментированный переключатель**: `[ Видео | Фото VK ]`.
* **Видеоархив**: 80 официальных трансляций и обзоров с фильтрами по годам и платформам (Все / Rutube / VK), плеер 16:9 с автоматическим центрированием при выборе ролика.
* **Фотогалерея**: 19 альбомов соревнований, адаптивная сетка карточек, полноэкранный свайп-лайтбокс с поддержкой мобильных жестов и клавиатуры.

### 5. Рекорды России (`records`)
* 321 рекорд России в дисциплинах многоборья ГТО.
* Сегментированный фильтр пола: `[ Все | Мужчины | Женщины ]`.
* Капсульные фильтры по возрасту, спортивной дисциплине и вариантам группировки.
* Интерактивные строки: тап по рекорду открывает модальное окно шеринга с генерацией диплома-достижения.

### 6. Калькулятор ступеней ГТО (`calculator`)
* Официальные нормативы I–XVIII ступеней Минспорта России (Приказ № 114).
* Сегментированный переключатель пола (`Мужской` / `Женский`) и интерактивный бегунок возраста (6–79 лет) с разметкой ступеней.
* Реактивная оценка введенного результата с подсветкой: **Золото**, **Серебро**, **Бронза** или **Ниже нормы**.
* Сравнение личного результата с действующим рекордом России.
* Блок официальных льгот: налоговый вычет 18 000 руб., до 10 дополнительных баллов к ЕГЭ, повышенная академическая стипендия.
* Экспорт карточки выполнения нормативов в социальные сети.

### 7. Тренировочный таймер WOD (`timer`)
* Режимы: **Табата** (8×20/10с), **EMOM** (каждую минуту), **AMRAP** (максимум раундов за время), **For Time** (на время с лимитом).
* Крупные спортивные цифры, цветная индикация фаз (Подготовка, Работа, Отдых, Финиш).
* Автономный звук через Web Audio API (громкий стартовый и обратный отсчет) без внешних аудиофайлов.
* Быстрые пресеты популярных тренировок многоборья ГТО.

### 8. Судейские стандарты (`standards`)
* Регламенты выполнения упражнений: отжимания, подтягивания, рывок гири, прыжок в длину, наклон.
* Критерии зачета и четкий перечень причин незачета (No-Rep).

### 9. Федерация и сервисы (`more`)
* О Федерации, история развития спорта (1930–2026), состав руководящих органов.
* Интерактивная карта 49 региональных отделений с расчетом дистанции по GPS.
* Документы: Устав, свидетельства Минюста, правила вида спорта.
* Антидопинг: материалы РУСАДА, контакты ответственного, ссылки на сервис проверки препаратов.

## 💻 Технологический стек

### Frontend / Web App:
* **Архитектура**: Vanilla JavaScript (ES6+ Modules) — без оверхеда тяжелых фреймворков, мгновенная загрузка на любых мобильных устройствах.
* **Стилизация**: Модульный CSS3 с переменными (`--bg`, `--card`, `--line`, `--text`), Glassmorphism (`backdrop-filter`), Safe Area Insets (`env(safe-area-inset-bottom)`).
* **Типографика**: `Unbounded` (геометрический дисплейный шрифт для спортивных заголовков и рекордов) + `Inter` (высокочитаемый интерфейсный шрифт).
* **Графика**: Инлайн SVG-векторы (Zero-Emoji Vector Standard) для четкости на Retina-дисплеях.
* **Canvas API**: Генерация брендированных графических карточек достижений в реальном времени.
* **Web Audio API**: Синтез звуковых частот для таймера тренировок.
* **PWA & Офлайн**: Service Worker с версионированным кэшированием ядра и данных (`v21`).

### Android Client:
* **Язык**: Kotlin 1.9+
* **UI**: Jetpack Compose (Material 3)
* **Архитектура**: Android Edge-to-Edge WebView Client с поддержкой аппаратного ускорения, системного скачивания файлов (DownloadManager) и геолокации.

## 🚀 Локальный запуск и разработка

Для запуска веб-приложения не требуются сложные сборщики или Node.js зависимости. Достаточно любого статического веб-сервера:

```bash
# 1. Клонирование или переход в каталог репозитория
cd /Users/mak/antigravity/ФМГТО-РФ

# 2. Запуск локального сервера (через Python 3)
python3 -m http.server 3000 --directory web

# Или через Node.js serve:
npx serve web -p 3000
```

Приложение будет доступно по адресу: **`http://localhost:3000`**.

### Проверка синтаксиса JavaScript:
```bash
node -c web/js/mobile.js && node -c web/sw.js
```

Приложение развернуто на боевом сервере под управлением **Nginx**:

* **Адрес**: `root@201.51.30.44`
* **Каталог на сервере**: `/var/www/gto2026/`
* **Порт**: `8080`

### Команда синхронизации и деплоя:

```bash
# Синхронизация файлов и перезагрузка Nginx:
rsync -avz -e "ssh -i ~/.ssh/crossfit_prod_ed25519 -o StrictHostKeyChecking=no" web/ root@201.51.30.44:/var/www/gto2026/ \
  && ssh -i ~/.ssh/crossfit_prod_ed25519 -o StrictHostKeyChecking=no root@201.51.30.44 "nginx -s reload"
```

### Проверка статуса сервера:
```bash
ssh -i ~/.ssh/crossfit_prod_ed25519 -o StrictHostKeyChecking=no root@201.51.30.44 "curl -sI http://127.0.0.1:8080/"
```
