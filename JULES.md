# Многоборье ГТО — PWA (гид для агента)

Мобильное PWA-приложение **Федерации многоборья ГТО России**: календарь соревнований,
результаты, рекорды России, медиа (VK/Rutube), интерактивная карта регионов, калькулятор
нормативов ВФСК ГТО, тренировочные инструменты и личный кабинет «Герой ГТО».

Живая версия: `https://201-51-30-44.sslip.io` (первоисточник данных: `https://gto.com.ru`).

## Стек

- **Vanilla JS, ES-модули, без фреймворков.** Точка входа — `web/index.html`, грузит
  `web/js/mobile.js` (`<script type="module">`), который импортирует модули данных и
  динамически — `herogto_module.js` (кабинет атлета).
- **SPA с hash-роутингом:** экраны — `data-screen="..."`, переходы — `data-go="..."`
  (`#home`, `#events`, `#records`, `#media`, `#regions`, `#calculator`, `#timer`,
  `#standards`, `#hero`, `#more` и т.д.).
- **CSS:** токены + модули в `web/css/` (`tokens, mobile, detail, autonomy,
  gto-moscow-features, mobile-polish, desktop`). Тёмная тема, CSS custom properties.
- **PWA:** `web/manifest.webmanifest` + `web/sw.js` (офлайн-кэш, версия `const VERSION='vN'`).

## Структура

```
web/
  index.html            — оболочка SPA, весь верхний UI (хедер, дровер, экраны)
  js/
    mobile.js           — основной код приложения (~11k строк)
    herogto_module.js   — личный кабинет «Герой ГТО» (паспорт с QR, видеофиксация)
    *_data.js           — данные (нормативы, регионы, амбассадоры, FAQ, стандарты)
    ecosystem_sync.js   — единый доступ к данным (records/news/events/federations)
    vendor/             — qrcode.min.js, jsQR.min.js (локально, офлайн)
  css/                  — 7 файлов стилей (порядок подключения важен, см. index.html)
  data/                 — реальные данные из gto.com.ru (json): события, результаты, рекорды
  assets/               — иконки, логотипы, гербы регионов
docs/                   — ТЗ и аудиты (в т.ч. TZ_OPTIMIZATION_MENU_V171.md)
server_source/          — бэкенд/вспомогательные скрипты
```

## Запуск локально

```bash
cd web
python3 -m http.server 8000
# открыть http://localhost:8000
```
Сборка не нужна — это статический SPA. Node только для проверки синтаксиса: `node --check web/js/mobile.js`.

## Конвенции проекта (важно соблюдать)

1. **Только реальные данные.** Никаких выдуманных цифр, статусов, имён — источник `gto.com.ru`.
   Все счётчики (114 стартов, 321 рекорд, 49 отделений, 3 203 атлета) — из данных.
2. **Zero-Emoji в UI:** иконки — инлайн-SVG, не эмодзи.
3. **Кэш-бастинг при релизе:** поднимать `?v=N` у ассетов в `index.html` (и импортах `mobile.js`)
   **и** `const VERSION='vN'` в `sw.js` — иначе immutable-кэш/Service Worker отдаст старое.
4. **Порядок CSS в `<head>`** менять нельзя без причины — `autonomy.css` и
   `gto-moscow-features.css` содержат стили баннеров, фильтров и карты регионов.

## Чего в репозитории нет (исключено намеренно)

Тяжёлая медиа и приватное: пользовательские видео (`web/uploads/`), крупные баннеры
событий, VK-фотоальбомы, PNG-презентации, sqlite-дампы, `.env` (секреты), деплой-скрипты.
Код на них ссылается — файлы лежат на проде/`gto.com.ru`.
